The core, in the browser

These are not values JavaScript computed. They come out of pacific-core compiled to wasm — the same canonical CBOR envelope, the same sha256, the same SAS wordlist the phone uses. The expected strings are pinned by a native Rust test (core-wasm, vectors::fixture_is_stable). If the envelope layout ever changes, both sides move together or one of them goes red.
