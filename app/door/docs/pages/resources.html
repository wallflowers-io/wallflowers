The Resources editor

WallFlowers' editor for a community's resources, in your page: write a post, add pictures and a PDF, preview it, and publish it to the community.

The script

<script src="{{DOOR}}/v2/resources.js"
        integrity="{{RESOURCES_SRI}}"
        crossorigin="anonymous"></script>

Load it after the sign-in script, pinned by the hash above, the current release's. It changes only when the Door is released.

Mount it

const session = await WallFlowers.current({ client });
const editor = WallFlowersResources.mount(document.getElementById('editor'), {
  fetch: session.fetch,
  site: session.site,
  onSaved: ({ post, published }) => { /* read /v2/graph again */ }
});
Option
fetchsession.fetch: the editor writes as the member.
siteThe community the post is published to: session.site.
postA post to edit, by id. Leave it out to write a new one.
onSavedCalled after each save with the post's id and whether it is published.

editor.dirty is true while there are unsaved changes; editor.close() takes it out of the page.

What it writes

ButtonOps
Save draftmint a post; post.setProfile (the body as markdown), post.setMedia (the cover), post.setDocument (the PDF), post.addAsset and post.removeAsset (its pictures)
Publishthe same, then group.setAffiliation {rel: created} on the community and base.setBacklink on the post: the community names it, and it names the community
Updatewhat changed
Unpublishgroup.clearAffiliation and base.clearBacklink; the post stays a draft

A post's body is CommonMark 0.31.2, and its pictures are its own: the body shows them as asset:<id>. Each picture, the cover and the PDF is sized to fit the model's caps before it is sent (The model, post).

A site's session reaches its community and what it made. A post made elsewhere is edited in WallFlowers.

In this release

  • Every post is public. The editor offers no visibility choice: each post it publishes is on the community's public page, for anyone.
  • Large pictures and PDFs stay off the public page. On the post's public page ({{ARC}}/v1/face/<slug>/post/<id>, and its /document), a picture or PDF over 16 KB doesn't appear: a picture shows its alt text, and a large PDF has no link. Members see everything in WallFlowers.
  • The public page renders part of Markdown. Paragraphs, headings, code, rules, quotes, lists, emphasis, inline links and images are drawn. Reference-style links, entities (&amp;), autolinks (<https://…>) and raw HTML show there as the text they are. Write links inline: [text](https://…).
  • No PDF thumbnail in the editor on your site. Mounted on your site, the editor doesn't show a PDF's first-page thumbnail: the PDF renderer it loads isn't served to other sites yet.
