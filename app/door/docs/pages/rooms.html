Open a room

The owner, in one batch: mint a forum with its name, base.setPart on the community, base.setParent on the room. A new room has only its owner in it; members are added in WallFlowers.

Threads

Draw a room as threads, each reply under what it answers, the order WallFlowers' own apps use:

  1. A message's parent is its reply_to, but only if that names another message in the room. Otherwise it's top-level.
  2. Sort siblings by ts (the author's clock, in ms), then author, then gen. gen counts each author's own messages, so it is not a clock across people.
  3. Walk the tree depth-first, recording each message's depth. Anything left unvisited (a reply cycle) becomes top-level, in the same order.

Every message appears exactly once. For a flat list, sort by ts.
