The listings board

A community's Trade board. A member lists something of theirs, every member reads the board, and the owner or an admin can take a listing down. In this release it is the board only: no deal can be opened yet, so buying and selling happen between the people, off the board.

The thing

A listing points at a thing the member owns. Your site mints one in a batch, and then it is in your session's reach:

{ "steps": [
  { "do": "mint", "kind": "thing", "draft": { "name": "A bike" } },
  { "do": "apply", "object": { "$step": 0 }, "op": "thing.setPosture",
    "args": { "posture": "selling", "price": "£40", "reach": "network" } } ] }

posture is one of has · wants · offers · buying · selling, and a price only goes with buying or selling. reach is network or private.

ToOp, on the thingArgsWho
Describe itthing.setProfilename; condition: new · like_new · very_good · good · fair · for_parts; description (up to 5000 characters, several lines); descriptor (one line)its owner
Add a photothing.addPhotoid (16 hex, chosen by you), photo (base64, at most 150,000 characters) and photoMime (an image type), at (ms, the photos' order)its owner; at most 20
Remove a photothing.removePhotoid. A removed id stays removed.its owner
Reserve it · mark it soldthing.setDispositionstate: available · reserved · sold; with reserved, for (the member's key) and until (ms); at (ms)its owner

The thing is the lister's own, and they alone read its view: condition, description, photos (by at) and disposition, where a reservation past its until reads available. Other members don't see those: they see the listing on the board.

The board

A listing is a snapshot, and it is all other members see of the thing: its title, descriptor, price, posture, area, deadline and one photo, as the lister last listed it. Change the thing, then list it again. Read the board from the community's view in GET /v2/graph:

const { objects } = await (await session.fetch('/v2/graph')).json();
const community = objects.find((o) => o.id === session.site);
for (const l of community.view.listings ?? []) drawListing(l);
// author, thingId, posture, title, reach, rev, site, gen;
// when given: descriptor, price, area, deadline, photo, photoMime

Only live listings are there: not withdrawn, not taken down. Show Take down only to the owner and admins, as with roles.
