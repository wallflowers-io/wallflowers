What you read

GET /v2/graph answers { me, objects, spine }: who you are, every object you can read, and spine, which is always empty ([]) for a site.

Every object

Field
idThe object's id, 64 hex characters.
kindgroup (the community), forum (a room), host (its public page), treasury, …: see the model.
nameIts name: a room's name, the community's name.
owner · membersKeys, 64 hex characters.
peer · roleFor a conversation between two people; null for everything a site reads.
folds · whyWhether it could be read here, and if not, why.
viewIts current state, by kind (below).

Keys. A key appears as 64 hex characters everywhere except me.pk (and /v2/me's pk), which carry an ed25519: prefix. They are the same key: strip the prefix to compare (pk.replace(/^ed25519:/, '')).

      "members": ["9442…3a2e", "0224…b1f0"], "peer": null, "role": null, "folds": true, "why": null,
      "view": { "display_name": "Mill Road Allotments", "shape": "community",
                "parts": [ { "part": "3481…", "role": "room", "at": 1790600000000 } ],
                "roles": [], "profiles": { "9442…3a2e": { "name": "Hana", "icon": null, "gen": 1 } },
                "publication": { "slug": "mill-road", "publisher": "9442…3a2e" } } },
    { "id": "3481…", "kind": "forum", "name": "General", "owner": "9442…3a2e",
      "members": ["9442…3a2e", "0224…b1f0"], "peer": null, "role": null, "folds": true, "why": null,
      "view": { "messages": [ { "author": "0224…b1f0", "gen": 1, "text": "Hello!", "ts": 1790600100000,
                                "reply_to": null, "up": 0, "down": 0, "reactions": [] } ],
                "parent": { "parent": "71c1…6a6c", "role": "room" } } } ],
  "spine": [] }

folds: false means the object couldn't be read on this device, and why says why. Show it as unavailable, never drop it silently.

The community (kind: "group")

{ "display_name": "Mill Road Allotments", "shape": "organisation",
  "roles":   [ ["0224…", "admin"] ],
  "offices": [ { "office": "treasurer", "holder": "…", "status": "accepted", "at": 1790… } ],
  "parts":   [ { "part": "3481…", "role": "room", "at": … }, { "part": "c48a…", "role": "host", "at": … } ],
  "membership": [ { "member": "…", "present": true, "tenures": [ … ] } ],
  "profiles": { "<member key>": { "name": "Hana", "icon": { "mime": "image/webp", "data": "<base64>" } | null, "gen": 3 } },
  "decisions": { … }, "face": { "look": { … }, … } | null }

The owner is the object's owner. roles lists who holds which role. The community's rooms are its parts with role room, in at order; a room that isn't in the graph isn't in the member's reach.

A room (kind: "forum")

{ "messages": [ { "author": "0224…", "gen": 12, "text": "…", "ts": 1790…,
                  "reply_to": { "author": "…", "gen": 9 } | null,
                  "up": 3, "down": 0, "reactions": [ ["❤️", 6, true], ["🌱", 3, false] ] } ],
  "profiles": { … },
  "parent": { "parent": "<community>", "role": "room" } }

A message is identified by author + gen. ts is milliseconds, 0 when not given. Each reaction is [emoji, count, mine]. The room's name is the object's name. A room's profiles also carries members who have left: merge it with the community's.

Names

A person's name is profiles[key].name from the community's or the room's view; your own is me.display_name. Anyone else without a card is New member. Never show a key as a name. A site reads cards and never writes one: members edit theirs at {{DOOR}}/#you.

The page (kind: "host") and the treasury

The page: { name, parent, publication, media: { mark | cover | logo | wallpaper: { mime, data } }, items }. The treasury: { open, currency, balance, bands, deposits, settlements, … }, amounts in the currency's smallest unit.

Events and resources are linked to the community rather than part of it, so a member's session doesn't reach them: read them from the public page.
